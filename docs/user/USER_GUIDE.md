# Bakery ERP - User Guide

## Getting Started
Welcome to Bakery ERP. This application manages your daily production, sales, and employee wages entirely offline.

## Core Workflows
1. **Starting the Day**: Navigate to the "Working Day" screen and "Open Day". No transactions can occur without an open day.
2. **Sales**: Press `F2` or navigate to Sales to create an invoice. If the app crashes, your draft will be recovered on next launch!
3. **Production**: Use the Production view to consume Raw Materials (Flour) and produce Finished Goods (Bread). The system will automatically calculate piecework wages for the assigned employees.

## Settings & Printing
- Navigate to the `Settings` screen to toggle **Dark Mode** or **Arabic RTL Layout**.
- Connect your 80mm thermal printer. The application will use your Windows Default Printer for thermal receipts.

## System Health & Backups
- The **Health Monitor** shows your active database size and disk space.
- Backups are taken automatically, but you can trigger a manual backup from the Settings/Backup menu at the end of every shift.
- The system retains the last 30 backups to save space.
